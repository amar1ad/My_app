آخر تحديث: 30 مايو 2026

1. مقدمة

مرحباً بك في تطبيق "قاموس المبرمج" (المشار إليه بـ "التطبيق" أو "نحن" أو "لنا"). نحن ندرك أهمية خصوصية بياناتك، ونلتزم بحمايتها. توضح هذه السياسة كيفية تعاملنا مع أي معلومات يتم جمعها عند استخدامك للتطبيق.

📌 ملخص سريع: تطبيق "قاموس المبرمج" لا يجمع أي بيانات شخصية من المستخدمين العاديين. جميع البيانات (المصطلحات، الدروس، المفضلة) تُخزن محلياً فقط على جهازك ولا تُرسل إلى أي خادم خارجي.

2. ما هي البيانات التي نجمعها؟

أ. للمستخدمين العاديين (الذين يستخدمون التطبيق للتعلم):

  • لا نجمع أي بيانات شخصية على الإطلاق.
  • التطبيق لا يطلب أذونات الوصول إلى جهات الاتصال، الموقع، الكاميرا، الميكروفون، أو الملفات الشخصية.
  • لا يتم استخدام أي خدمات تحليلات (مثل Google Analytics أو Firebase) لتتبع سلوكك.
  • جميع المصطلحات والدروس والمحتوى التعليمي تُخزن داخل جهازك فقط باستخدام قواعد بيانات SQLite و SharedPreferences.

ب. لمديري التطبيق (لوحة التحكم):

إذا كنت تمتلك صلاحيات الوصول إلى لوحة التحكم الإدارية (التي تُستخدم لإدارة المحتوى)، فقد تقوم بـ:

  • رفع ملف data.json إلى مستودع GitHub الشخصي الخاص بك (للمزامنة فقط).
  • رفع صور مخصصة (مثل أيقونات التصنيفات أو الصور التوضيحية) إلى مجلد images/ في مستودع GitHub الخاص بك.

نحن لا نصل إلى هذه البيانات ولا نخزنها على خوادمنا؛ بل تُرفع مباشرة إلى حساب GitHub الخاص بك.

3. كيف نستخدم بياناتك؟

نظراً لأننا لا نجمع أي بيانات، فإننا لا نستخدمها لأي غرض. البيانات التي تُخزن محلياً على جهازك تُستخدم فقط من أجلك أنت لعرض المصطلحات والدروس وإدارة المفضلة.

4. تخزين البيانات ومكانها

  • جميع بيانات المستخدم العادي تُخزن فقط على جهازك الفعلي. لا يتم نقلها أو نسخها إلى أي خادم خارجي.
  • بيانات المسؤول (الخاصة بمالك لوحة التحكم) تُرفع إلى حساب GitHub الشخصي الخاص بك. أنت وحدك من تتحكم بهذه البيانات.

5. أمان البيانات

نحن نأخذ أمان بياناتك على محمل الجد. على الرغم من أننا لا نجمع بيانات، إلا أننا نوصي بما يلي:

  • حافظ على تحديث جهازك بنظام أندرويد.
  • لا تقم بتثبيت التطبيق من مصادر غير موثوقة.
  • إذا كنت تستخدم لوحة التحكم، احرص على استخدام رمز وصول شخصي (Personal Access Token) آمن لـ GitHub ولا تشاركه مع أي شخص.

6. روابط خارجية وخدمات طرف ثالث

قد يحتوي التطبيق على روابط خارجية (على سبيل المثال، روابط مرجعية لمصادر إضافية ضمن الدروس). عند النقر على هذه الروابط، قد تغادر التطبيق وتنتقل إلى مواقع خارجية. نحن لسنا مسؤولين عن ممارسات الخصوصية لتلك المواقع.

التطبيق يستخدم GitHub API فقط في حالة استخدام لوحة التحكم الإدارية (لنشر البيانات). لا يتم استخدام أي خدمات طرف ثالث أخرى.

8. حقوقك (للمستخدمين في المنطقة الاقتصادية الأوروبية والمملكة المتحدة)
